# BingX Pump Monitor Bot

Приложение для автоматического мониторинга резких скачков цены (пампов) на бирже BingX с фильтрацией по рыночной капитализации и отправкой уведомлений в Telegram.

## Основные возможности

- **Сканирование BingX**: Мониторинг всех USDT-M пар (фьючерсы).
- **Фильтрация Market Cap**: Только монеты с капитализацией > $20,000,000.
- **Фильтрация по объему**: Суточный объем торгов (24h Volume) > $5,000,000.
- **Три уровня сигналов**:
  - 🚨 **MEGA Pump**: >30% за час.
  - ⚠️ **Pump**: >15% за час.
  - 📈 **Low Pump**: >7% за час.
- **Защита от дублей**: Коины не спамят повторно в течение часа.
- **Кэширование**: Использование SQLite для хранения истории цен.

## Установка

1. **Клонируйте репозиторий или скачайте файлы.**
2. **Установите Python 3.8+**
3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Настройте переменные окружения:**
   - Создайте файл `.env` (или используйте шаблон).
   - `TELEGRAM_BOT_TOKEN`: Токен вашего бота от @BotFather.
   - `TELEGRAM_CHAT_ID`: ID канала или чата, куда слать сигналы.

## Запуск

```bash
python main.py
```

## Структура проекта

- `main.py`: Точка входа.
- `config.py`: Настройки порогов и таймингов.
- `scanner.py`: Логика обнаружения пампов.
- `exchange.py`: Взаимодействие с BingX (ccxt).
- `market_cap.py`: Получение данных о капитализации (CoinGecko).
- `database.py`: Работа с базой данных (SQLite).
- `bot.py`: Отправка сообщений в Telegram (aiogram).
- `bot_data.db`: Локальная база данных (создается автоматически).
